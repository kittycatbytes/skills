# Skills

Agent skills for Cursor. Each skill is a folder with a `SKILL.md` file.

## company-hiring-site

Builds a recruiter-facing page in the stack and palette of a company's public website, then puts it on GitHub and Firebase Hosting.

https://github.com/kittycatbytes/skills/tree/main/skills/company-hiring-site

Install it for every project:

```bash
gh skill install kittycatbytes/skills company-hiring-site --agent cursor --scope user
```
